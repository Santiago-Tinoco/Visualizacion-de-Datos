6 Boxplot

p_box <- ggplot(sismos, aes(y = magnitud, x = "Todos los sismos")) +
  geom_boxplot(fill = "orange") +
  labs(title = "Boxplot de magnitudes sísmicas", x = NULL, y = "Magnitud") +
  theme_minimal()

ggplotly(p_box)

Boxplot por año, útil para comparar visualmente reciente vs. histórico — al pasar el mouse sobre cada caja se ven mediana, cuartiles y outliers:

p_box_anio <- ggplot(sismos, aes(x = factor(anio), y = magnitud)) +
  geom_boxplot(fill = "lightblue") +
  labs(title = "Distribución de magnitud por año",
       x = "Año", y = "Magnitud") +
  theme_minimal() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1))

ggplotly(p_box_anio)
