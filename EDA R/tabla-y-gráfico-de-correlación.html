9 Tabla y gráfico de correlación

Incluye variables de calidad/error del catálogo (nst, gap, dmin, rms, horizontalError, depthError, magError, magNst), útiles para ver, por ejemplo, si la profundidad se relaciona con el error de magnitud o si el gap (cobertura de estaciones) afecta la calidad de detección.

vars_numericas <- sismos %>%
  select(magnitud, profundidad, latitud, longitud,
         nst, gap, dmin, rms, horizontalError, depthError, magError, magNst) %>%
  drop_na()

matriz_corr <- cor(vars_numericas, use = "complete.obs")
knitr::kable(round(matriz_corr, 3), caption = "Matriz de correlación")
