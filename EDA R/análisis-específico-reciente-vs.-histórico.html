10 Análisis específico: ¿reciente vs. histórico?

Se define una ventana “reciente” y se compara contra el resto del histórico usando varias pruebas complementarias. Como el dataset ya está filtrado a magnitud ≥ 5 (eventos poco frecuentes) y ahora está acotado a una sola región, una ventana de 30 días puede quedarse con muy pocos eventos — se incluye una validación automática que sugiere ampliarla si es necesario.

# Ajusta el número de días según tu definición de "reciente" y la sismicidad
# típica de tu región (regiones menos activas necesitan ventanas más largas)
DIAS_RECIENTE <- 1825 #Ultimos 5 años

fecha_corte <- max(sismos$fecha) - days(DIAS_RECIENTE)

sismos <- sismos %>%
  mutate(periodo = if_else(fecha >= fecha_corte, "reciente", "historico"))

n_check_reciente  <- sum(sismos$periodo == "reciente")
n_check_historico <- sum(sismos$periodo == "historico")

cat("Eventos en período reciente:", n_check_reciente, "\n")
## Eventos en período reciente: 83
cat("Eventos en período histórico:", n_check_historico, "\n")
## Eventos en período histórico: 506
if (n_check_reciente < 10) {
  warning("Muy pocos eventos en el período 'reciente' (n < 10). ",
          "Los tests estadísticos tendrán poca potencia; considera aumentar DIAS_RECIENTE.")
}

mag_reciente  <- sismos %>% filter(periodo == "reciente") %>% pull(magnitud)
mag_historico <- sismos %>% filter(periodo == "historico") %>% pull(magnitud)

10.1 Ley de Gutenberg-Richter: valor-b (reciente vs. histórico)

La relación de Gutenberg-Richter (log10(N) = a - b*M) describe cuántos sismos de cada magnitud se esperan en una región: el valor-b resume esa relación y es el indicador estándar en sismología para saber si el patrón de magnitudes de un período es “el esperado”. Un valor-b que cae marcadamente (más sismos grandes relativos a los pequeños) suele interpretarse como señal de posible cambio en el régimen de esfuerzo de la falla; valores-b estables (~1) son lo típico en la mayoría de las regiones.

Se estima con el estimador de máxima verosimilitud de Aki: b = log10(e) / (magnitud_media - magnitud_minima).

calcular_b <- function(magnitudes) {
  mag_min <- min(magnitudes)
  b <- log10(exp(1)) / (mean(magnitudes) - mag_min)
  b
}

b_reciente  <- calcular_b(mag_reciente)
b_historico <- calcular_b(mag_historico)

cat("Valor-b período reciente:", round(b_reciente, 3), "\n")
## Valor-b período reciente: 1.089
cat("Valor-b período histórico:", round(b_historico, 3), "\n")
## Valor-b período histórico: 1.087
cat("Diferencia (reciente - histórico):", round(b_reciente - b_historico, 3), "\n")
## Diferencia (reciente - histórico): 0.002
# Gráfico log-lineal de Gutenberg-Richter por período:
# log10(N de sismos con magnitud >= M) vs. M, por período
gr_simple <- sismos %>%
  group_by(periodo) %>%
  reframe(
    magnitud_umbral = sort(unique(magnitud)),
    n_mayor_igual = sapply(magnitud_umbral, function(m) sum(magnitud >= m))
  )

p_gr <- ggplot(gr_simple, aes(x = magnitud_umbral, y = n_mayor_igual, color = periodo)) +
  geom_point() +
  geom_line() +
  scale_y_log10() +
  labs(title = "Relación de Gutenberg-Richter por período",
       x = "Magnitud (M)", y = "N° de sismos con magnitud ≥ M (escala log)",
       color = "Período") +
  theme_minimal()

ggplotly(p_gr, tooltip = c("x", "y", "colour"))

Una caída notable en el valor-b reciente respecto al histórico (proporción mayor de sismos grandes frente a pequeños) es, junto con los tests de tasa de ocurrencia y de distribución de abajo, una de las señales más citadas en sismología para sospechar de un cambio de régimen.

10.2 Serie temporal con gráfico de control

Conteo semanal de eventos comparado contra bandas de ±2 desviaciones estándar de la media histórica (excluyendo el período reciente).

conteo_semanal <- sismos %>%
  count(semana, name = "n_eventos")

hist_stats <- conteo_semanal %>%
  filter(semana < fecha_corte) %>%
  summarise(media_hist = mean(n_eventos), sd_hist = sd(n_eventos))

p_serie <- ggplot(conteo_semanal, aes(x = semana, y = n_eventos)) +
  geom_line(color = "steelblue") +
  geom_point() +
  geom_hline(yintercept = hist_stats$media_hist, color = "black", linetype = "solid") +
  geom_hline(yintercept = hist_stats$media_hist + 2*hist_stats$sd_hist,
             color = "red", linetype = "dashed") +
  geom_hline(yintercept = hist_stats$media_hist - 2*hist_stats$sd_hist,
             color = "red", linetype = "dashed") +
  geom_vline(xintercept = as.numeric(fecha_corte), color = "darkgreen", linetype = "dotted") +
  labs(title = "Conteo semanal de sismos vs. bandas de control (±2 SD histórica)",
       subtitle = "Línea verde punteada = inicio del período 'reciente'",
       x = "Semana", y = "N° de eventos") +
  theme_minimal()

ggplotly(p_serie, tooltip = c("x", "y"))

10.3 Test de tasa de ocurrencia (Poisson)

Los catálogos sísmicos se modelan como procesos de conteo; este test compara si la tasa de eventos por día en el período reciente difiere de la histórica (más robusto que comparar solo el número absoluto de eventos).

n_reciente     <- sum(sismos$periodo == "reciente")
n_historico    <- sum(sismos$periodo == "historico")
dias_reciente  <- as.numeric(max(sismos$fecha) - fecha_corte)
dias_historico <- as.numeric(fecha_corte - min(sismos$fecha))

test_poisson <- poisson.test(
  x = c(n_reciente, n_historico),
  T = c(dias_reciente, dias_historico)
)
test_poisson

10.5 Comparación de distribuciones completas: Kolmogorov-Smirnov

Compara toda la forma de la distribución de magnitudes, no solo la media; útil si sospechas que cambió la proporción de sismos grandes aunque la media se mantenga similar.

test_ks <- ks.test(mag_reciente, mag_historico)
test_ks

10.6 Z-score de la actividad reciente

media_hist_mag <- mean(mag_historico)
sd_hist_mag    <- sd(mag_historico)

z_score_reciente <- (mean(mag_reciente) - media_hist_mag) / sd_hist_mag

tasa_hist_diaria     <- n_historico / dias_historico
tasa_reciente_diaria <- n_reciente / dias_reciente

cat("Z-score de la magnitud media reciente respecto a la histórica:",
    round(z_score_reciente, 2), "\n")
## Z-score de la magnitud media reciente respecto a la histórica: 0
cat("Tasa histórica (eventos/día):", round(tasa_hist_diaria, 3), "\n")
## Tasa histórica (eventos/día): 0.012
cat("Tasa reciente (eventos/día):", round(tasa_reciente_diaria, 3), "\n")
## Tasa reciente (eventos/día): 0.045
