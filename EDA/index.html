Dataset: Significant_Earthquakes.xlsx — catálogo USGS, ~115.500 sismos, 22 variables (1900–2023)

1. Planteamiento del problema¶

¿la actividad sísmica reciente de una región está estadísticamente fuera de lo esperado** respecto a su comportamiento histórico?

1.2¶

Introducción¶

Este documento realiza un análisis exploratorio de datos (EDA) de un catálogo sísmico (formato USGS) con el objetivo de responder la pregunta:

¿La actividad sísmica reciente en una región está estadísticamente fuera de lo esperado respecto a su comportamiento histórico?

Se presentan estadísticas descriptivas, visualizaciones estándar de EDA (histograma, boxplot, densidad, Pareto, correlación) y un bloque de pruebas estadísticas específicas para comparar el período reciente contra el histórico.

Notas importantes sobre este dataset Cobertura global: incluye sismos de todo el mundo desde 1900. Comparar “reciente vs. histórico” sin filtrar por región mezclaría zonas de altísima actividad (Cinturón de Fuego del Pacífico) con zonas de baja actividad (Europa, África), lo cual invalida cualquier comparación. El filtro por región es obligatorio, no opcional, y se aplica justo después de cargar los datos. Filtrado por magnitud ≥ 5: el dataset solo reporta sismos mayores de 5. Esto significa que el histograma/densidad de magnitud estarán truncados por la izquierda (no es una distribución normal “completa”), y es la razón por la que se añade el análisis de la Ley de Gutenberg-Richter (valor-b) más adelante, que es el estándar en sismología para caracterizar la distribución de magnitudes.

1.3 Carga y preparación de datos¶

Dataset tipo catálogo USGS con columnas: time, latitude, longitude, depth, mag, magType, nst, gap, dmin, rms, net, id, updated, place, type, horizontalError, depthError, magError, magNst, status, locationSource, magSource

time y updated pueden venir en dos formatos según la fuente exacta del CSV: como milisegundos desde el epoch Unix (formato original de la API de USGS) o ya como texto/fecha ISO8601 (formato común en versiones redistribuidas, p. ej. en Kaggle). El código detecta automáticamente cuál es el caso.

1.5 Marco teórico¶

  1. Actividad sísmica y catálogos de terremotos

Los terremotos son eventos asociados a la liberación súbita de energía acumulada en la corteza terrestre, principalmente como consecuencia de la deformación y ruptura de materiales sometidos a esfuerzos tectónicos. Los catálogos sísmicos reúnen información de estos eventos, incluyendo variables como tiempo de ocurrencia, coordenadas geográficas, profundidad, magnitud y diferentes parámetros relacionados con la calidad de la localización.

El presente análisis utiliza un catálogo de aproximadamente 115.500 eventos registrados entre 1900 y 2023, con 22 variables asociadas a cada evento. Entre las variables principales se encuentran la latitud, longitud, profundidad, magnitud, tipo de magnitud, localización y estado de revisión del evento.

  1. Análisis exploratorio de datos

El análisis exploratorio de datos (EDA) permite estudiar las características principales de un conjunto de datos antes de realizar inferencias o establecer modelos. Incluye procedimientos como estadística descriptiva, análisis de distribuciones, identificación de valores faltantes, detección de valores extremos y evaluación de relaciones entre variables.

En este trabajo, el EDA se desarrolla mediante análisis univariado, bivariado e inferencial, utilizando medidas de tendencia y dispersión, asimetría, curtosis, histogramas, KDE, boxplots, correlaciones y pruebas estadísticas.

  1. Completitud y sesgo temporal del catálogo sísmico

Un aspecto fundamental de los catálogos sísmicos es que la capacidad de detección de eventos no ha sido constante a lo largo del tiempo. El desarrollo de las redes sismológicas y de los instrumentos de registro produjo un aumento considerable en la cantidad de sismos detectados, especialmente durante la segunda mitad del siglo XX.

Por esta razón, comparar directamente la actividad registrada en periodos antiguos con la actividad reciente puede generar falsas anomalías asociadas al mejoramiento de la capacidad de detección, y no a cambios reales en la actividad sísmica. El notebook identifica este problema y establece 1968 como inicio de la línea base histórica, buscando trabajar con un periodo de mayor estabilidad en la tasa de detección.

  1. Magnitud y distribución de los sismos

La magnitud representa una medida logarítmica relacionada con el tamaño de un terremoto. Debido a su naturaleza, la distribución de las magnitudes sísmicas no se comporta como una distribución normal. En el catálogo analizado, la magnitud presenta una distribución asimétrica y una cola hacia valores altos, comportamiento característico de los datos sísmicos.

Además, el análisis considera una magnitud de completitud (M_c=5.0), a partir de la cual se considera que el catálogo presenta una cobertura adecuada para los análisis de distribución de magnitudes.

  1. Ley de Gutenberg–Richter

La ley de Gutenberg–Richter describe la relación entre la magnitud de los terremotos y su frecuencia de ocurrencia. Se expresa como:

log⁡10N(≥M)=a−bM\log_{10}N(\geq M)=a-bMlog10​N(≥M)=a−bM
(1)

donde (N(\geq M)) corresponde al número acumulado de sismos con magnitud igual o superior a (M), (a) representa el nivel general de actividad sísmica y (b) describe la proporción relativa entre terremotos pequeños y grandes.

El parámetro (b)-value es particularmente útil para comparar poblaciones sísmicas. Una variación en este parámetro puede indicar un cambio en la distribución relativa de los tamaños de los eventos. El notebook estima el (b)-value mediante máxima verosimilitud y utiliza posteriormente el test de Utsu para comparar el comportamiento reciente con el histórico.

  1. Proceso de Poisson y ocurrencia de sismos

Para estudiar la frecuencia temporal de los terremotos, el trabajo utiliza como modelo nulo un proceso de Poisson homogéneo. Este modelo permite representar el número de eventos que ocurren durante una unidad determinada de tiempo bajo una tasa histórica (\lambda):

Nr,t∼Poisson(λr)N_{r,t}\sim Poisson(\lambda_r)Nr,t​∼Poisson(λr​)
(2)

donde (N_{r,t}) representa el número de sismos registrados en la región (r) durante el periodo (t), mientras que (\lambda_r) corresponde a la tasa histórica de ocurrencia de esa región.

Para aplicar este modelo, el catálogo de eventos puntuales se transforma en un panel región × mes, incluyendo también los meses en los que no se registraron terremotos. Esto permite obtener una estimación consistente de la tasa histórica de ocurrencia.

  1. Definición estadística de anomalía

En este trabajo, una anomalía sísmica no se define simplemente como un aumento visual en el número de terremotos. Una región se considera anómala cuando su actividad reciente presenta una probabilidad suficientemente baja bajo el comportamiento histórico esperado.

Por tanto, el análisis compara los conteos recientes de cada región con su tasa histórica y evalúa la significancia estadística mediante pruebas de tasa de Poisson, considerando además la corrección por múltiples comparaciones.

  1. Sobredispersión y agrupamiento sísmico

El proceso de Poisson supone una relación específica entre la media y la varianza de los conteos. Sin embargo, la actividad sísmica puede presentar agrupamiento temporal, especialmente debido a secuencias de réplicas posteriores a terremotos principales. Esto puede producir una varianza superior a la esperada bajo un modelo de Poisson simple.

Por esta razón, el análisis incorpora una corrección cuasi-Poisson por sobredispersión y utiliza el índice de dispersión como parte del diagnóstico estadístico. También se analiza la distribución de los tiempos entre eventos para evaluar la presencia de agrupamiento.

  1. Control estadístico de la actividad sísmica

Otra herramienta utilizada es la carta de control de Shewhart de 3σ, aplicada a los conteos de actividad sísmica después de utilizar una transformación estabilizadora de la varianza. Esta herramienta permite identificar periodos en los cuales la actividad observada se aleja de los límites establecidos a partir del comportamiento histórico.

En conjunto, el notebook utiliza tres líneas principales de evidencia para evaluar anomalías: tasa de ocurrencia mediante Poisson, control estadístico mediante 3σ y cambios en la distribución de magnitudes mediante Gutenberg–Richter y el test de Utsu.

  1. Representación espacial y temporal

Para realizar una comparación objetiva entre regiones, el espacio se divide mediante una malla de 5° × 5°, asignando cada evento a una celda espacial. Esta regionalización permite transformar el catálogo puntual en unidades comparables y analizar simultáneamente la variabilidad espacial y temporal de la actividad sísmica.

2.6 División de los datos: 80 % histórico / 20 % reciente¶

Decisión metodológica crítica: la división NO puede ser aleatoria.

Una partición aleatoria mezclaría meses de 1990 con meses de 2023 en ambos conjuntos, destruyendo el orden temporal y produciendo data leakage: el “histórico” contendría información del futuro. Como la pregunta es explícitamente “reciente vs. histórico”, la división debe ser cronológica:

  • 80 % más antiguo → conjunto HISTÓRICO (train): línea base de la que se estiman λr\lambda_rλr​, el b-value y los límites de control.

  • 20 % más reciente → conjunto RECIENTE (test): periodo bajo evaluación, nunca usado para estimar la línea base.

Esta partición cumple el lineamiento 80/20 y define operativamente la pregunta de investigación.

def panel_univariado(serie, nombre, unidad="", bins=50, log_x=False):
    """Histograma normalizado + densidad de kernel + boxplot para una variable."""
    s = pd.Series(serie).dropna().astype(float)
    fig, (ax1, ax2) = plt.subplots(
        2, 1, figsize=(10, 5.4), sharex=True,
        gridspec_kw={"height_ratios": [3.2, 1], "hspace": 0.08})

    sns.histplot(s, bins=bins, stat="density", kde=True, color="#4C72B0",
                 edgecolor="white", linewidth=0.3, ax=ax1,
                 line_kws={"lw": 2.2, "color": "#C44E52"})
    ax1.axvline(s.mean(), color="#55A868", ls="--", lw=1.8, label=f"Media = {s.mean():.2f}")
    ax1.axvline(s.median(), color="#8172B2", ls="-.", lw=1.8, label=f"Mediana = {s.median():.2f}")
    ax1.set_ylabel("Densidad")
    ax1.set_title(f"{nombre} — histograma normalizado + KDE  "
                  f"(asimetria={stats.skew(s):+.2f}, curtosis={stats.kurtosis(s):+.2f})")
    ax1.legend(fontsize=8)

    sns.boxplot(x=s, ax=ax2, color="#4C72B0", width=0.5,
                flierprops={"markersize": 2.5, "alpha": 0.35})
    ax2.set_xlabel(f"{nombre} {unidad}".strip())
    if log_x:
        ax1.set_xscale("log")
        ax2.set_xscale("log")

    # Regla de Tukey para atipicos
    q1, q3 = s.quantile([0.25, 0.75])
    iqr = q3 - q1
    lo, hi = q1 - 1.5 * iqr, q3 + 1.5 * iqr
    n_out = int(((s < lo) | (s > hi)).sum())
    plt.tight_layout()
    plt.show()
    print(f"   Bigotes de Tukey: [{lo:.2f} , {hi:.2f}]  |  "
          f"atipicos: {n_out:,} ({n_out / len(s) * 100:.2f} %)")
    return n_out / len(s) * 100

titulo("15. Ley de Gutenberg-Richter y estimacion del b-value")

MC = 5.0            # magnitud de completitud del catalogo
DELTA_M = 0.1       # resolucion de binning de la magnitud


def b_value_aki(magnitudes, mc=MC, dm=DELTA_M):
    """Estimador MLE de Aki (1965) del b-value, con su error estandar."""
    m = np.asarray(pd.Series(magnitudes).dropna(), dtype=float)
    m = m[m >= mc]
    n = len(m)
    if n < 30:
        return np.nan, np.nan, n
    media = m.mean()
    denom = media - (mc - dm / 2.0)
    if denom <= 0:
        return np.nan, np.nan, n
    b = np.log10(np.e) / denom
    sigma = b / np.sqrt(n)                      # error estandar de Aki
    return b, sigma, n

titulo("19. Asociacion entre variables CATEGORICAS: chi-cuadrado y V de Cramer")


def v_cramer(tabla):
    chi2 = stats.chi2_contingency(tabla)[0]
    n = tabla.values.sum()
    r, k = tabla.shape
    phi2 = chi2 / n
    # correccion de sesgo de Bergsma (2013)
    phi2c = max(0, phi2 - (k - 1) * (r - 1) / (n - 1))
    rc = r - (r - 1) ** 2 / (n - 1)
    kc = k - (k - 1) ** 2 / (n - 1)
    return np.sqrt(phi2c / max(min(kc - 1, rc - 1), 1e-12))

def bateria_normalidad(serie, nombre, n_shapiro=45, n_rep=200):
    """Shapiro-Wilk sobre submuestras pequenas + D'Agostino + K-S(Lilliefors) + Anderson-Darling."""
    s = pd.Series(serie).dropna().astype(float)
    n = len(s)
    res = {"Variable": nombre, "n": n}

    # --- Shapiro-Wilk sobre submuestras de n<50 (repetido para estabilidad) ---
    if n >= n_shapiro:
        ps = [stats.shapiro(s.sample(n_shapiro, random_state=i)).pvalue for i in range(n_rep)]
        res["Shapiro p (mediana de %d submuestras n=%d)" % (n_rep, n_shapiro)] = float(np.median(ps))
        res["% submuestras que rechazan"] = float(np.mean(np.array(ps) < ALPHA) * 100)
    else:
        res["Shapiro p (mediana de %d submuestras n=%d)" % (n_rep, n_shapiro)] = stats.shapiro(s).pvalue
        res["% submuestras que rechazan"] = np.nan

    # --- D'Agostino-Pearson K^2 -------------------------------------------
    res["DAgostino p"] = stats.normaltest(s).pvalue if n >= 20 else np.nan

    # --- K-S tipo Lilliefors (parametros estimados de la muestra) ----------
    z = (s - s.mean()) / s.std(ddof=1)
    res["KS p"] = stats.kstest(z, "norm").pvalue

    # --- Anderson-Darling (critico al 5 %) ---------------------------------
    ad = stats.anderson(s.sample(min(n, 20000), random_state=RANDOM_STATE), dist="norm")
    res["AD estadistico"] = float(ad.statistic)
    res["AD critico 5%"] = float(ad.critical_values[2])
    res["AD rechaza"] = bool(ad.statistic > ad.critical_values[2])
    res["Asimetria"] = float(stats.skew(s))
    res["Curtosis"] = float(stats.kurtosis(s))
    return res

def indice_dispersion(conteos):
    """Test chi-cuadrado de equidispersion de Poisson."""
    x = np.asarray(conteos, dtype=float)
    n = len(x)
    media = x.mean()
    if n < 10 or media <= 0:
        return np.nan, np.nan, np.nan
    D = (n - 1) * x.var(ddof=1) / media
    p = 1 - stats.chi2.cdf(D, df=n - 1)      # unilateral: sobredispersion
    return D, p, x.var(ddof=1) / media       # D, p-valor, phi

def bh_fdr(pvals):
    """Correccion de Benjamini-Hochberg: devuelve los q-valores (FDR ajustada)."""
    p = np.asarray(pvals, dtype=float)
    n = len(p)
    orden = np.argsort(p)
    q = np.empty(n)
    minimo = 1.0
    for rango in range(n - 1, -1, -1):
        idx = orden[rango]
        minimo = min(minimo, p[idx] * n / (rango + 1))
        q[idx] = minimo
    return np.clip(q, 0, 1)


phi_por_region = dispersion.set_index("region")["phi"].to_dict()
resultados = []

for reg, g in panel.groupby("region"):
    gh = g[g["periodo"] == "HISTORICO"]["n_eventos"]
    gr = g[g["periodo"] == "RECIENTE"]["n_eventos"]
    Th, Tr = len(gh), len(gr)                 # exposicion en meses
    Xh, Xr = int(gh.sum()), int(gr.sum())
    if Xh + Xr < 10:                          # muestra insuficiente para inferencia
        continue

    lam_h = Xh / Th                           # tasa historica (sismos/mes)
    lam_r = Xr / Tr                           # tasa reciente
    esperado_bruto = lam_h * Tr               # esperado sin corregir la deriva global
    esperado = esperado_bruto * F_GLOBAL      # esperado ESTANDARIZADO

    # --- (1) Test EXACTO condicional de dos tasas de Poisson (estandarizado) ---
    # Bajo H0, Xr | (Xh+Xr) ~ Binomial(Xh+Xr, p0), con la exposicion reciente
    # ponderada por el factor de deriva global f.
    p0 = (Tr * F_GLOBAL) / (Th + Tr * F_GLOBAL)
    bt = stats.binomtest(Xr, Xh + Xr, p0, alternative="two-sided")
    p_exacto = bt.pvalue
    lo, hi = bt.proportion_ci(confidence_level=0.95, method="exact")
    # IC de la razon de tasas ESTANDARIZADA (RTE)
    rte_lo = (lo / (1 - lo)) * (Th / (Tr * F_GLOBAL)) if lo < 1 else np.nan
    rte_hi = (hi / (1 - hi)) * (Th / (Tr * F_GLOBAL)) if hi < 1 else np.inf

    # --- (2) Z CUASI-POISSON: varianza inflada por el factor de dispersion -----
    phi = max(phi_por_region.get(reg, 1.0), 1.0)

    p_quasi = 2 * (1 - stats.norm.cdf(abs(z_q))) if np.isfinite(z_q) else np.nan

    z_bruto = ((Xr - esperado_bruto) / np.sqrt(phi * esperado_bruto)
               if esperado_bruto > 0 else np.nan)

    # Poisson puro sin estandarizar: el criterio "ingenuo" que se quiere evitar
    z_ing = ((Xr - esperado_bruto) / np.sqrt(esperado_bruto)
             if esperado_bruto > 0 else np.nan)
    p_ingenuo = 2 * (1 - stats.norm.cdf(abs(z_ing))) if np.isfinite(z_ing) else np.nan

    resultados.append({
        "region": reg,
        "region_nombre": g["region_nombre"].iloc[0],
        "meses_hist": Th, "meses_rec": Tr,
        "n_hist": Xh, "n_rec": Xr,
        "tasa_hist": lam_h, "tasa_rec": lam_r,
        "esperado_rec": esperado,
        "exceso": Xr - esperado,
        "razon_tasas": lam_r / lam_h if lam_h > 0 else np.nan,      # bruta
        "RTE": Xr / esperado if esperado > 0 else np.nan,           # estandarizada
        "RTE_IC_inf": rte_lo, "RTE_IC_sup": rte_hi,
        "phi": phi,

def test_utsu(b1, n1, b2, n2):
    """Utsu (1992): contraste de igualdad de dos b-values basado en AIC."""
    if not all(np.isfinite([b1, b2])) or min(n1, n2) < 2 or b1 <= 0 or b2 <= 0:
        return np.nan, np.nan
    N = n1 + n2
    dA = (-2 * N * np.log(N)
          + 2 * n1 * np.log(n1 + n2 * b1 / b2)
          + 2 * n2 * np.log(n1 * b2 / b1 + n2)
          - 2)
    return dA, float(min(np.exp(-dA / 2 - 2), 1.0))
